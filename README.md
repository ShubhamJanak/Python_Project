# Python_Projects
Calculator :
A simple Python calculator that performs basic math operations like addition, subtraction, multiplication, and division.

Mad Libs Game :
A fun Python game where you enter random words to create a silly and funny story!

Compound Interest Calculator : 
A Python program that calculates compound interest using principal, rate, and time to show investment growth.

Temperature Conversion :
A Python program that converts temperature values between Celsius, Fahrenheit, and Kelvin quickly and accurately.

Number Guessing Game :
A simple Python game where players get 3 chances to guess a randomly generated number.

Countdown Timer :
A simple Python countdown timer that takes time in seconds and displays a live countdown in minutes and seconds until the timer reaches zero.

Report Card Printer :
A beginner Python script demonstrating basic data types (string, boolean, integer, float) using `type()` and `isinstance()`.

Employee Profile Generator :
A beginner Python project that uses string concatenation, f-strings, and slicing to build employee profiles and parse employee codes.

Employee Profile Validator :
A Python utility that cleans, validates, and formats employee records (names, emails, phone numbers, addresses, and employee codes) using built-in string methods.

Bill Splitter :
A Python tool that totals meal costs, adds a tip, and calculates how much each person owes.

Movie Ticket Calculator : 
A Python tool that uses booleans and conditional statements to calculate movie ticket prices based on booking details.

Travel Weather Planner :
A Python tool that uses conditional statements to decide whether a commute is possible based on weather, distance, and vehicle availability.

Kitchen Inventory Tracker : 
A Python tool that uses reusable functions and local and global scope to track and manage kitchen inventory.
